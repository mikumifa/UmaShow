# UmaShow Monte Carlo core

This directory contains the minimal handwritten-logic and Monte Carlo subset
adapted from [UmaAi](https://github.com/hzyhhzy/UmaAi) at commit
`e855d52e6bf7284269df84ab61aca4f687c19b26`.

It intentionally excludes the neural-network backends, model files, training
tools, WebSocket client, UI, and the original `db` directory. Runtime character
and support-card data is generated by UmaShow from `master.mdb` into
`assets/data/monte_carlo.json`.

The adapted UmaAi sources are distributed under the license in
`LICENSE.UmaAi.txt`.

Bundled source dependencies:

- `External/json.hpp`: JSON for Modern C++ 3.11.2, MIT license. Copyright
  2013-2022 Niels Lohmann.
- `External/termcolor.hpp`: termcolor, BSD license. Copyright 2013 Ihor
  Kalnytskyi.

The JSONL bridge and CMake project are UmaShow-specific adaptations.
